# 교육계획서 (2026 가을학기)

「2026학년도 가을학기 교육계획서」(등대교육공동체) 서식을 웹에서 작성하고,
인쇄(PDF)와 Word(.docx)로 내보내는 도구.

원본 서식: `(Template) 2026등대 교육계획서(교과명,학년)교사명.docx`

## 쓰는 법

빌드 도구도 설치도 필요 없다. `index.html` 을 브라우저로 열면 끝.
로컬 서버로 띄우려면:

```sh
python3 -m http.server 8787
# → http://localhost:8787
```

## 기능

- **학년 탭 7개** — M6 · M7 · M8 · H9 · H10 · H11 · H12. 각각 독립된 계획서 한 부.
  탭에 점(•)이 붙어 있으면 작성된 내용이 있다는 뜻.
- **저장** — `저장` 버튼 또는 <kbd>⌘S</kbd>. 입력을 멈추면 1.2초 뒤 자동 저장도 된다.
  저장 안 된 상태에서 창을 닫으려 하면 브라우저가 경고한다.
- **인쇄 / PDF** — <kbd>⌘P</kbd>. 편집 UI 없이 원본과 같은 A4 표 서식으로 출력된다.
  브라우저 인쇄 창에서 «PDF로 저장» 선택.
- **Word (.docx)** — 원본의 표 구조와 열너비(twips)를 그대로 재현한 파일을 내려받는다.
  파일명은 원본 규칙대로 `2026등대 교육계획서(과목,학년)교사명.docx`.
- **백업 / 복원** — `⋯` 메뉴에서 7개 학년 전체를 `.json` 한 파일로 내보내고 되돌린다.
- **다른 학년으로 복사** — 한 학년을 다 쓰고 나머지 학년에 복사한 뒤 10절만 손보는 용도.

### 입력 칸과 고정 문구

학교 공통 정책(2·4·5가·5다·6·7·8절)은 회색 블록으로 표시되고 편집되지 않는다.
문구를 바꿔야 하면 `template.js` 한 파일만 고치면 화면·인쇄·docx 에 함께 반영된다.

교사가 채우는 곳: 머리표 6칸 · 1가 과목 개요 · 1나 교육 철학 · 3 학습 목표 ·
5나 성적 반영 비율 · 6 과목별 추가 규정 · 9 핵심 가치 선택 · 10 단원별 지도계획 18행.

**5나 성적 반영 비율**은 과목마다 달라서 영역 자체를 고칠 수 있게 열어 뒀다.
영역 이름·비율·세부 내용을 고치고, `+ 평가 영역 추가` 로 행을 늘리고, 오른쪽 `×` 로 지운다.
기본 5개 항목(인성 30 / 수업내 활동 15 / 숙제 15 / 중간고사·프로젝트 20 / 기말고사 20)은
그대로 들어 있고, 합계가 100% 가 아니면 합계 행이 주황색으로 경고한다.

## 데이터가 어디 있나

브라우저 `localStorage` (키: `lessonplan.2026fall.v1`) **한 곳뿐이다.**
다른 컴퓨터에서 이어 쓰거나, 브라우저 데이터를 지울 일이 있거나, 시크릿 창을 쓴다면
반드시 `⋯ → 전체 백업 내보내기(.json)` 를 먼저 할 것.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `template.js` | 서식의 원본 — 고정 문구, 학사일정, 표 열너비, 블록 생성 |
| `docx.js` | 의존성 없는 .docx 작성기 (STORE 방식 zip + WordprocessingML) |
| `app.js` | 편집기 · 저장 · 인쇄 · 내보내기 |
| `styles.css` | 화면 편집기 + 인쇄(A4) 레이아웃 |

## 학사일정 표기

10절의 「일시」 칸은 `template.js` 의 `SCHEDULE` 배열 하나에서 나온다. 일정이 바뀌면 여기만 고친다.

바로잡은 항목:

- 2주차 `8/17 광복절` → **`8/17 광복절 대체휴일`**
  (2026년 광복절 8/15 는 토요일이라 8/17 월요일이 대체휴일)

원본 표기를 그대로 둔 항목:

- 12주차 `12/26-10/30` — `10/26-10/30` 의 오타로 보이나 확인 전이라 유지

### 미리 채워 둔 단원명

10절 「단원명」 칸 네 곳은 7개 학년 모두 같은 값으로 미리 들어가 있다.
일반 입력값이라 지우거나 고쳐 쓸 수 있다. 값은 `template.js` 의 `SCHEDULE_DEFAULTS` 에 있다.

| 일시 | 단원명 |
|---|---|
| 8/14 (예비소집) | 수업없음 |
| 8/17-21 | Orientation |
| 10/5-10/9 | Review Test — 중간고사 전주 |
| 12/07~12/11 | Review Test — 기말고사(12/14-12/16) 전주 |

**중간고사 주간은 원본 학사일정에 표기가 없다.** 학기 중간이고 기념 주간(10/19-10/23)·
상담 주간(10/29-10/30)과 겹치지 않는 `10/12-10/16` 을 중간고사로 보고 그 전주에 넣었다.
실제 중간고사가 다른 주라면 `SCHEDULE_DEFAULTS` 의 키 `8` 을 해당 주의 전주 인덱스로 바꾸면 된다.

이미 저장된 문서에도 한 번만 자동으로 채워지며, **교사가 이미 써 둔 칸은 덮어쓰지 않는다.**
